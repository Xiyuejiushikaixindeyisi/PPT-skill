# 版式库（封面 / 目录 / 节标题 / 内容页 / 末尾页）

坐标为页面百分比 `(x, y) 宽×高`，左上角为原点。页面 13.333×7.5in，1% 宽 ≈ 0.133in，1% 高 ≈ 0.075in。
以下骨架直接来自部门真实文件的线框提取（layout-skeletons.md）；标注"推断"的部分为样本未覆盖、按同风格补全。
`scripts/dept_pages.py` 已把这五个版式封装成函数，优先调用函数而不是手摆坐标。

## 1. 封面（cover）

来自「管报产品2026年工作规划」等 4 份文件第 1 页，结构完全一致：

```
主标题    ( 5.4,  8.8)  80×39   40–48pt 加粗 黑，左对齐，底部对齐锚点
副标题    ( 5.4, 56.4)  50×4.8  14pt 黑（汇报场合 / 一句话说明）
落款      ( 5.4, 91.0)  14×3.4   9pt 灰（部门 · 日期）
logo      右下角，宽 1.5in
```

可选：主标题上方加一条 2683C6 细条（0.06in 高、1.2in 宽）作视觉锚点（推断，样本中约半数封面有类似元素）。

## 2. 目录（toc）

样本仅 1 页目录（目录页版式），骨架推断如下，与内容页同风格：

```
页标题 "目录"  ( 5.5, 1.7)  89×8   20pt 加粗
条目区        ( 5.5, 16) 起，每条一行：
  序号块  0.45×0.45in  2683C6 底 白字 14pt（01/02/…）
  条目文字  紧随其后    14pt 黑，左对齐
  条目底   整行 D7EAFE 或白底 + D9D9D9 下分隔线
条目行高 0.55–0.7in，最多 8 条；超过分两栏
```

## 3. 节标题（section）

secHead 版式在各文件均有使用；内页骨架推断：

大序号    ( 5.4, 30)   —      60pt 加粗 2683C6（"01"）

细线      (14.0, 44)  40×0.15 2683C6 1pt
副说明    (14.0, 47)  70×6    12pt 灰（本节要点一句话，可选）
logo      右下角
```

## 4. 内容页（content）——最重要

页标题带来自实测（89% 内容页一致）：

```
页标题带  ( 5.5, 1.7)  89×8   20pt 加粗 黑，左对齐，无下划线、无装饰条
主图区    ( 3.0, 11) ~ (97, 95)   高度 ≥ 页高 70%
logo      右下角（主图避开右下 1.5×0.4in）
```

主图区内容 = 从 `references/motif-library.md` 选 1 个主 motif（架构分层 / 泳道 / 甘特 /
chevron 生命周期 / 象限 / as-is→to-be …）+ 至多 2 个辅 motif（图例、KPI 条、mini 表）。
密度目标：形状数 ≥ 20（中位数 30），无 > 1.2in 空白方块。所有卡片直角、扁平、无阴影。

标题写法惯例（从样本归纳）：结论式长标题，如"XX 通过 XX 实现 XX，预计 XX"，
而不是名词短语"XX 介绍"。

logo      右下角
```

## 页面顺序模板

标准汇报结构：封面 → 目录 → [节标题 → 内容页×N]×节数 → 末尾页。
≤6 页的短材料可省目录与节标题。
