# 部门风格规范（dept-flat-blue）

数据来源：9 份真实部门 PPT / 237 页 / 9313 个形状的自动提取 + 人工复核。
本文件区分**明确规范**（跨文件一致、高频出现）与**个人习惯噪声**（个别作者或个别模板才有）。
机器可读版本在 `assets/tokens.json`，脚本只认 tokens.json。

## 一、对 tokens-draft.json 的修正（为什么和草稿不一样）

| 草稿值 | 修正为 | 原因 |
|---|---|---|
| `caption`/`min` = 4pt | caption 9pt / min 8pt | 4pt 是提取噪声（图元里的极小标注）。真实字号分布最低常用档是 8pt（占 15%），8pt 以下不可读 |
| `nested` = FFC8D3（粉） | DEEBF7（浅蓝二级容器） | 粉色来自红主题那批文件；蓝主题中的二级浅底是 DEEBF7。粉色保留为可选对比色 `pink` |
| `border_blue` = FFC000 | 2683C6 | FFC000 是琥珀色，槽位标错；保留为高亮色 `amber` |
| `title` = 24pt | 20pt（页标题） | title 占位符实测 20pt 占 62%、24pt 占 34%。封面标题另设 `cover_title` 40pt |
| `today_line` = 2683C6 | C00000 | 部门里红色 C00000 是强调惯例（80 次填充 + 336 次文字），今日线用红更醒目。若想低调可改回 |
| `min_shapes` = 20 | 保留 20（页面形状中位数 30，P75=58） | 20 为硬性下限；正常内容页应奔着 30+ 去做 |

## 二、明确规范（必须遵守）

- **页面**：13.333 × 7.5 in（16:9），白底，无背景图案。
- **转角**：直角为主（圆角仅占 12%，且多数 adj≈0 即视觉直角）→ 一律画直角矩形。
- **扁平**：不用阴影（实测仅 3.2%）、不用渐变（3.3%）、纯色填充。
- **字体**：中文微软雅黑，西文跟随中文字体（+mn-ea）。latin/ea/cs 三个槽都写微软雅黑。
- **主视觉色**：#2683C6；浅底容器 #D7EAFE；标题与正文文字 #000000。
- **描边**：常用线宽 0.5 / 0.75 / 1.0 pt；灰色系描边（BFBFBF / D9D9D9）或无描边（27% 形状显式无边框）。
- **箭头**：连接线端点用 triangle（96%）；实线为主，虚线（dash / lgDash）只用于"规划中/弱关联"。
- **对齐**：容器内文字居中为主（80%），说明性长文本左对齐；行距 1.0 为主。
- **项目符号**：默认无符号（80%）；需要列表时用 `•`。
- **文字自适应**：形状随文字缩放（resize-shape）为主，禁止 shrink 到 8pt 以下。

## 三、常用色板（按实测频次）

| 用途 | 色值 | token | 说明 |
|---|---|---|---|
| 主视觉 / 强调填充 | 2683C6 | accent | 深蓝节点、当前阶段、激活状态 |
| 一级浅底容器 | D7EAFE | container | 分组框、卡片底 |
| 二级浅底 | DEEBF7 | nested | 嵌套子块 |
| 中性底 | F0F0F2 | neutral | 未开始 / 弱化区块 |
| 强调红 | C00000 | red | 风险、红线、今日线、关键数字 |
| 高亮琥珀 | FFC000 | amber | 里程碑、待决策项 |
| 对比粉 | FFC8D3 | pink | 与蓝色系并列的第二分组色（少用） |
| 文字 | 000000 / 808080 | text / muted | 正文黑、辅助灰 |
| 边线 | BFBFBF / D9D9D9 | border_gray / gray_line | 卡片描边、分隔线 |

蓝色永远是第一分组色；需要第二、第三分组色时按 pink → amber 顺序取，不引入新色。

## 四、字号阶梯（pt）

| 档位 | 值 | 用在 |
|---|---|---|
| cover_title | 40 | 封面主标题（40–48 均可，加粗） |
| section_title | 28 | 节标题页大标题 |
| title | 20 | 内容页页标题（加粗、黑色、左对齐） |
| container_title | 14 | 分组框标题 |
| node_title / body | 12 | 节点标题、正文 |
| secondary | 10 | 次级说明 |
| caption | 9 | 图注、页脚、来源 |
| min | 8 | 硬性下限（QA FONTSIZE 门禁） |

## 五、形状语汇（按频次）

rect（矩形，5908 次）→ 一切卡片/节点/容器；
straightConnector1 / bentConnector3 → 流程连线（triangle 箭头）；
homePlate / chevron → 阶段推进条、生命周期；
ellipse → 起止节点、序号圆点；
rightArrow / downArrow → 强调方向；
leftBrace → 归纳汇总。
不要用云朵、旗帜、立体形状等花哨图元。

## 六、表格与图表

- 表格：无斑马纹为默认（仅 27% 启用）；表头可用浅蓝底（D7EAFE）+ 黑字，或白底加粗；线用 D9D9D9 0.5pt。
- 图表：柱状 / 折线为主；系列颜色按 accent → 558ED5 → 808080 取；**必须显示数据标签**（实测 4/4 都开）；图例放底部或不放；主网格线浅灰。

## 七、个人习惯噪声（不要学）

- 红黑主题的 theme1.xml（E9002F / Arial Black）：来自公司级模板残留，部门实际用蓝。
- 圆角 adj=50000（胶囊形）：个别作者习惯，占比低。
- Open Sans / Noto Sans SC / -apple-system：从网页截图或粘贴带入，不是规范字体。
- 每页 4 个形状以下的"三张卡片式"内容页：属于低质量页，密度门禁禁止。

## 八、v2 补充实测惯例(第二轮 237 页挖掘 + 母版底稿量测)

### 页面家具(母版层,内容页每页都有)
| 元素 | 实测值 |
|---|---|
| 标题下通栏灰线 | y=9.8%,x 5.5%→94.4%,#BFBFBF,约 0.75pt |
| 左上角蓝色小图标 | (3.4%, 4.0%),高约 0.33in(素材 assets/corner-icon.png) |
| 左下角页码 | (4.4%, 95%),8pt 灰,格式 "page N" |
| 右下角 logo | 同 tokens logo 配置 |
封面/章节页/末尾页不带灰线与页码。`dept_pages.frame()` 负责绘制。

### 章节页真实版式(4 文件 ×15 页)
左侧 37.5% 全高 **#04194C 藏青栏**(可叠图片)+ 栏内 60pt 加粗白色大序号(11.3%, 43.4%);
右侧 x≈47.5% 竖向灰分隔线 + 议程列表:每节 = 小圆点 + "0X" 序号 + 节标题(20pt 加粗),
**当前节藏青色、其余灰 #808080**,当前节下可挂 2–3 张 F2F2F2 子卡片。
#04194C 深藏青为第二品牌色(另用于序号圆点)。

### 其余高置信惯例
- **红描边圈注**:#C00000 红色描边框是出现文件数最多的描边(7/9 文件 ×71),
  用于圈住页面重点区;红色虚线作分界/告警。
- **页顶分组导语标签**(9/9 文件):标题带下 y 11–14%、靠左的小标签块
  (直角矩形或 homePlate),10–14pt 加粗,D7EAFE 底或无底加粗字。
- **圆角边界修正**:圆角仅用于小标签 chip(≤1.1×0.5in,D7EAFE/FFC8D3 底);
  容器/卡片一律直角。QA SHAPE 门禁按此放行小 chip。
- **行内强调色体系**:蓝 #0070C0/#1066FC(术语)、红 #C00000 加粗(风险/关键数)、
  琥珀 #F4A100 加粗、次级灰 #333333。
- **结论式长标题为规则**:页标题 20 字以上占 67%,<10 字仅 2%。
- **行距 150% 专用于窄栏要点列表**(161 窄 vs 22 宽);宽段落用默认行距。
- **项目符号**:• 为主,Wingdings "Ø"(渲染为箭头)×135 亦是部门习惯。
- **形状零组合**(3615 顶层形状 grpSp=0):生成时平铺不打组,便于人工调整。
- **大图展示页**是常见页型:居中 60–90% 宽截图 + 标注(4 文件反复出现)。
- 色值修正:neutral=#F2F2F2(7 文件 ×125)、二级浅蓝 nested=#CFE0FE(4 文件;
  DEEBF7 仅 1 次证据不足)。
