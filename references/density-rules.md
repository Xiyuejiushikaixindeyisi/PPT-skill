# 密度规范与防留白机制（部门版）

最大的失败模式是退化成"三张卡片 + 大留白"。本文件把"密度"变成可度量的预算与门禁。
阈值以 `assets/tokens.json` 的 `density` 为准，`scripts/qa_check.py` 自动读取。

## 硬性指标（qa_check.py 强制）

| 指标 | 阈值 | 门禁 |
|---|---|---|
| 最大连续空白方块（去边距后） | ≤ 1.2in × 1.2in | HARD（density） |
| 主图高度 | ≥ 页高 70% | 设计期预算 |
| 墨水覆盖率（栅格化后） | < 30% 时告警 | soft |
| 内容页形状数 | ≥ 20（正常应 30+，样本中位数 30 / P75=58） | HARD（structure） |
| 单行文本溢出 | ≤ 可用宽度 3% | HARD（overflow） |
| 越界 / 意外重叠 | 0 | HARD（geometry） |
| 任何文字 < **8pt**（`min_font_pt`） | 0 | HARD（fontsize） |

HARD 门禁失败即 QA 非零退出，改完重跑，直到 `RESULT: PASS`。

## 设计期坐标预算（动手画之前先做）

1. 预留页标题带：y 1.7%–9.7%（约 0.13–0.73in）。
2. 主图区：y ≈ 11% 起，到页底 − 0.35in，高度 ≥ 70%。
3. 网格切分列/行，沟槽统一 0.20–0.30in。
4. 右下角给 logo 留 ≈1.5in × 0.4in 净空。
5. 把各部分加总——填不满主图区就欠"防留白填充"（见下）。

## 防留白填充优先级（依次套用，直到空白 ≤ 1.2in）

1. **扩主图**——给节点加注释、加嵌套子块、拉伸行高列宽占满区域。
2. **加辅助层**——图例、状态说明、KPI 圆点条、风险/依赖侧注、量化标注（"链路环节 XX+"）。
3. **加小面板**——mini 表格，或输入→输出示例。
4. 1–3 都不适用时才允许 ≤ 1.2in 的小空白。

禁止的"假填充"：把字号放大超出阶梯、撑大沟槽、拉一个大框盖住空白。这些看起来是凑数不是密度。

## 迭代时定位空白

`qa_check.py` 逐页打印墨水占比和最大空白方块位置。失败时找到该区域，按上面的优先级补。
常见元凶：左边高图旁边的短右栏、卡片内只有一行字。

## 字号适配原则

文字放不下时：先缩短措辞 → 换行 → 加宽容器，**绝不**把字号压到 8pt 以下。
9–10pt 只给图注和次级说明用；正文保持 12pt。
